# Localization

Status: Draft

- Czech is the default application locale.
- English is the second built-in locale.
- All system user-interface strings MUST be localizable.
- Built-in meal-role tags and other system presets MUST have Czech and English
  labels.
- User-entered content is stored as entered and is not automatically translated.
- User-entered content includes recipe names, ingredient names, notes, custom tags,
  and shopping-list additions.
- Locale-sensitive formatting MUST cover dates, decimal numbers, quantities, and
  currency.
- Every organization has a default currency, initially CZK. Each event inherits and
  then retains one currency for its budget, estimates, and receipts.
